# Saga-Elite-Prototype

Saga Elite limited-edition fashion platform prototype built with HTML, CSS, JavaScript, and Tailwind CSS.

## Run Prototype

1. From the repository root, start a local static server.
2. Open the project at http://localhost:5500 (or the port your server shows).

Example:

```bash
npx serve .
```

## Implemented Prototype Scope

1. Public pages:
	home, drops, drop detail, product detail, auth, cart, checkout, orders, order detail, profile, notifications.
2. Admin pages:
	dashboard, drops, products, orders, home-images, notifications, whatsapp logs, gifts, account.
3. Shared assets:
	design tokens, reusable styling, mock data models, role switcher, cart/wishlist persistence, checkout simulation, gift-tier logic, realtime event toast simulation.

## Prompt Pack

1. Open [docs/claude-master-prototype-prompt.md](docs/claude-master-prototype-prompt.md).
2. Copy the entire prompt.
3. Paste it into Claude.
4. Run it to generate the full multi-page prototype.
